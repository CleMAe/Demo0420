# 统一接口约束（课程 Demo 级别）

## 适用范围

本约定适用于 Demo0420 项目中由各成员维护的前后端交互接口，主要用于确保 Demo 演示时各模块的请求和响应风格一致。

## 模块命名规则

- 所有模块名称以 `main.py` 中 `PRODUCTS_SEED` 的 `name` 字段为准。
- 前端在 `portal-demos.js` 中通过 `BY_NAME` 映射匹配，名称不一致会导致 Demo 加载失败。
- 不要随意重命名产品模块名称。

## 通用请求字段建议

| 字段 | 类型 | 说明 |
|------|------|------|
| `product_id` | int | 产品模块 ID，从 `/api/products` 获取 |
| 自定义输入字段 | string / select | 各模块按需定义，字段名使用 camelCase |

所有请求均需在 `Authorization` 头中携带 `Bearer <token>`。

## 通用响应字段建议

```
{
  "success": true,
  "data": { ... },
  "message": ""
}
```

失败时：

```
{
  "success": false,
  "data": null,
  "message": "错误描述"
}
```

## 错误返回格式建议

| HTTP 状态码 | 含义 | 典型场景 |
|-------------|------|----------|
| 200 | 成功 | 正常返回 |
| 401 | 未登录 | token 缺失或过期 |
| 403 | 无权限 | 角色不匹配 |
| 404 | 产品不存在 | 产品 ID 无效 |
| 422 | 参数校验失败 | 请求字段格式错误 |
| 500 | 服务端错误 | 未捕获异常 |

## 金融模块特殊字段

### 金融研报生成器

| 字段 | 类型 | 说明 |
|------|------|------|
| topic | string | 研报主题 |
| industry | string | 目标行业 |
| length | string | 篇幅：简版 / 标准 / 详细 |

### 信贷风控模型工作台

| 字段 | 类型 | 说明 |
|------|------|------|
| age_range | string | 年龄段 |
| income_level | string | 收入水平 |
| job_type | string | 职业类型 |
| loan_purpose | string | 贷款用途 |
| score | int | 风险评分（0-1000） |
| risk_level | string | 低风险 / 中风险 / 高风险 |
| suggestion | string | 审批建议 |

## 医疗模块特殊字段

### 医疗影像辅助诊断

| 字段 | 类型 | 说明 |
|------|------|------|
| caseId | string | 模拟检查号或病例 ID，不使用真实检查号 |
| modality | string | 影像模态：CT / MRI / X-Ray |
| bodyPart | string | 检查部位 |
| seriesName | string | 当前阅片序列 |
| annotationLabel | string | 当前候选标注名称 |
| confidence | number | 模拟算法置信度，范围 0-1 |
| triageLevel | string | 低优先级 / 中优先级 / 高优先级 |
| finding | string | 初筛候选提示 |
| reviewSuggestion | string | 医师复核建议 |
| reportDraft | string | 结构化报告草稿，必须包含非诊断声明 |

## 禁止事项

- 不要在请求或响应中传输真实密钥、token、身份证号、手机号等敏感信息。
- 不要修改 `PRODUCTS_SEED` 中其他同学的模块字段。
- 不要改变现有的 RBAC 权限判断逻辑。
- 不要在前端 Demo 函数中调用非本模块的外部 API。
