# 演示数据口径（课程 Demo 级别）

## 总则

本项目所有模块的演示数据均为 **模拟数据**，不接入真实业务系统、不引用真实数据库、不调用第三方生产 API。

## 数据来源声明

- 所有数据在 `portal-demos.js` 的前端演示函数中硬编码或模拟生成。
- 不使用真实个人、客户、患者、企业敏感信息。
- 不使用真实财务报表、信贷记录、医疗影像或患者病历。
- 所有模拟数据不构成投资建议、医疗诊断、法律意见或商业决策依据。

## 金融研报生成器 — 输入输出样例

### 输入样例

| 字段 | 示例值 |
|------|--------|
| 主题 | 消费电子 · 季度景气 |
| 行业 | 消费电子 |
| 篇幅 | 标准（6 段） |

### 输出样例

```
核心观点：
  需求端温和复苏，渠道库存回到健康区间；
  成本端原材料价格回落改善毛利空间。

风险提示：
  地缘政治扰动可能影响供应链稳定性；
  终端需求复苏节奏存在不确定性。

合规提示：
  本报告为 AI 模拟生成草稿，不构成投资建议。
```

| 字段 | 示例值 |
|------|--------|
| 年龄 | 25-35 |
| 收入水平 | 高（> 15K） |
| 职业类型 | 稳定（公务员/国企） |

### 输出样例

```
风险评分：752 / 1000
风险等级：低风险
审批建议：建议通过，授信额度可适当放宽。
Top 特征解释：
  收入负债比（贡献 22%）、职业稳定性（贡献 18%）为正向主要驱动因素。
```

## 免责声明模板

各金融模块 Demo 在界面醒目位置展示以下声明：

> ⚠ 演示数据，不构成投资建议 / 不用于真实信贷审批。
> 所有数字与观点为 AI 模拟生成，仅供参考。
> 未经人工复核与合规审核，不得作为决策依据。

## 敏感数据禁止事项

- 禁止在代码、响应、日志中出现真实的姓名、身份证号、手机号、银行卡号、家庭住址。
- 禁止使用真实企业名称、财报数据、股价数据。
- 禁止使用真实信贷审批记录或征信报告片段。
- 禁止将任何演示数据与真实业务系统关联。
